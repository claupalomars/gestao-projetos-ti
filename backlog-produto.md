# Backlog do Produto — CompraFácil

## 1. Objetivo

O Backlog do Produto reúne as funcionalidades e atividades necessárias para o desenvolvimento do aplicativo CompraFácil, organizadas de acordo com sua prioridade e importância para o usuário.

O objetivo é orientar o desenvolvimento do aplicativo, permitindo que as entregas sejam organizadas e acompanhadas durante as Sprints, utilizando a metodologia Scrum.

## 2. Descrição do produto

O CompraFácil será um aplicativo de compras online que permitirá aos usuários realizar cadastros, consultar produtos, gerenciar um carrinho de compras, finalizar pedidos e acompanhar suas compras.

## 3. Itens do Backlog

| ID | Funcionalidade | Descrição | Prioridade |
|---|---|---|---|
| PB01 | Cadastro de usuários | Permitir que novos usuários realizem seu cadastro na plataforma. | Alta |
| PB02 | Login | Permitir que usuários cadastrados acessem o aplicativo. | Alta |
| PB03 | Consulta de produtos | Disponibilizar uma lista de produtos para consulta. | Alta |
| PB04 | Pesquisa de produtos | Permitir que o usuário encontre produtos de seu interesse. | Média |
| PB05 | Gerenciamento do carrinho | Permitir adicionar e remover produtos do carrinho de compras. | Alta |
| PB06 | Finalização de pedidos | Permitir que o usuário conclua seu pedido. | Alta |
| PB07 | Acompanhamento de pedidos | Permitir que o usuário consulte o andamento de seus pedidos. | Média |
| PB08 | Testes e validação | Verificar o funcionamento das funcionalidades antes da entrega. | Alta |

## 4. Critérios de aceitação

- **Cadastro:** o sistema deve permitir o preenchimento e registro dos dados do usuário.
- **Login:** o usuário deve conseguir acessar sua conta com suas credenciais.
- **Consulta:** os produtos cadastrados devem ser apresentados para visualização.
- **Pesquisa:** o usuário deve conseguir localizar produtos.
- **Carrinho:** o usuário deve conseguir adicionar e remover produtos.
- **Pedidos:** o sistema deve permitir a finalização de um pedido.
- **Acompanhamento:** o usuário deve conseguir consultar o status do pedido.
- **Testes:** as funcionalidades devem ser verificadas antes da entrega.

## 5. Priorização

A priorização dos itens considera a importância de cada funcionalidade para o funcionamento do aplicativo.

As funcionalidades essenciais, como cadastro, login, consulta de produtos e gerenciamento do carrinho, possuem prioridade alta, pois são fundamentais para a experiência de compra.

As demais funcionalidades serão organizadas conforme a sequência de desenvolvimento e o planejamento das Sprints.

## 6. Organização e acompanhamento

O Product Backlog será utilizado como referência para o planejamento das Sprints.

Durante o desenvolvimento, os itens poderão ser revisados, detalhados e reorganizados conforme as necessidades identificadas no projeto.

O acompanhamento das atividades será realizado por meio de um quadro Kanban, permitindo visualizar as tarefas pendentes, em andamento e concluídas.

## 7. Resultado esperado

Com o Backlog do Produto estruturado, espera-se obter uma visão organizada das funcionalidades necessárias para o desenvolvimento do CompraFácil, facilitando a definição das prioridades, o planejamento das entregas e o acompanhamento da evolução do projeto.
