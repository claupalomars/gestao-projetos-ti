# Plano de Melhorias — Projeto CompraFácil

## 1. Objetivo

Definir ações para aprimorar o planejamento, a comunicação e o acompanhamento das atividades do projeto CompraFácil.

## 2. Ações de melhoria

| ID | Oportunidade identificada | Ação proposta | Prioridade |
|---|---|---|---|
| M01 | Falhas de comunicação | Realizar alinhamentos periódicos | Alta |
| M02 | Possíveis atrasos | Acompanhar o cronograma semanalmente | Alta |
| M03 | Falta de organização | Manter documentos atualizados | Média |
| M04 | Mudanças nos requisitos | Registrar e avaliar as solicitações | Alta |
| M05 | Dificuldade no acompanhamento | Atualizar o quadro Kanban | Média |

## 3. Acompanhamento das melhorias

As ações deverão ser acompanhadas durante as Sprints, verificando seu andamento e os resultados obtidos.

## 4. Resultados esperados

- Melhor organização das atividades.
- Maior controle dos prazos.
- Comunicação mais eficiente.
- Redução de falhas no acompanhamento.
- Melhoria contínua dos processos.

## 5. Considerações finais

O plano de melhorias contribui para aperfeiçoar a gestão do projeto e apoiar decisões mais eficientes.

*Observação: as ações são propostas e deverão ser avaliadas conforme o andamento real do projeto.*
