# Registro de Lições Aprendidas — Projeto CompraFácil

## 1. Objetivo

Registrar aprendizados obtidos durante o planejamento e acompanhamento do projeto CompraFácil, identificando oportunidades de melhoria para projetos futuros.

## 2. Pontos de aprendizado

| Área | Lição aprendida | Oportunidade de melhoria |
|---|---|---|
| Planejamento | Definir claramente o escopo desde o início | Evitar alterações não planejadas |
| Comunicação | Manter os envolvidos alinhados | Realizar atualizações periódicas |
| Prazos | Acompanhar as atividades continuamente | Identificar atrasos com antecedência |
| Organização | Registrar tarefas e responsabilidades | Facilitar o controle das entregas |
| Riscos | Identificar possíveis problemas antecipadamente | Preparar ações preventivas |

## 3. Dificuldades e oportunidades

As principais situações que devem ser observadas durante o projeto são:

- Possíveis atrasos nas atividades.
- Mudanças nos requisitos.
- Falhas de comunicação.
- Necessidade de ajustes no planejamento.

## 4. Boas práticas

- Manter a documentação atualizada.
- Definir responsáveis pelas atividades.
- Acompanhar os prazos.
- Registrar decisões importantes.
- Avaliar os resultados de cada Sprint.

## 5. Aplicação em projetos futuros

Os aprendizados registrados poderão contribuir para planejamentos mais eficientes, melhor comunicação entre os envolvidos e maior controle das atividades.

## 6. Considerações finais

A análise das lições aprendidas fortalece a melhoria contínua e contribui para o aperfeiçoamento dos processos de gestão de projetos.

*Observação: este documento apresenta aprendizados previstos inicialmente. As lições efetivamente aprendidas deverão ser atualizadas conforme experiências reais durante a execução do projeto.*
