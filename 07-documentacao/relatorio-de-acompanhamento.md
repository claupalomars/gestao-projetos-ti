# Relatório de Acompanhamento — Projeto CompraFácil

## 1. Objetivo

Acompanhar o desenvolvimento do projeto CompraFácil, verificando o andamento das atividades, cumprimento dos prazos e possíveis riscos.

## 2. Informações do projeto

- **Projeto:** CompraFácil
- **Metodologia:** Scrum
- **Duração estimada:** 12 semanas
- **Acompanhamento:** Por Sprint

## 3. Indicadores de acompanhamento

| Indicador | Finalidade |
|---|---|
| Atividades planejadas | Verificar o volume de tarefas previstas |
| Atividades concluídas | Acompanhar as entregas realizadas |
| Cumprimento dos prazos | Monitorar o cronograma |
| Riscos identificados | Antecipar possíveis problemas |
| Pendências | Registrar atividades que precisam de atenção |

## 4. Situação das atividades

O andamento das atividades será atualizado conforme a execução de cada Sprint, considerando as seguintes situações:

- A fazer;
- Em andamento;
- Em revisão;
- Concluído.

## 5. Pontos de atenção

- Acompanhar possíveis atrasos.
- Verificar se os requisitos estão sendo atendidos.
- Manter a comunicação entre os envolvidos.
- Registrar dificuldades e ações corretivas.

## 6. Considerações finais

O relatório permite acompanhar a evolução do projeto, apoiar a tomada de decisões e manter as atividades organizadas.

*Observação: documento-modelo. Os indicadores e resultados deverão ser preenchidos conforme o andamento real do projeto.*
