# Plano de Comunicação — Projeto CompraFácil

## 1. Objetivo

Estabelecer diretrizes para a comunicação entre as partes interessadas, garantindo que as informações do projeto sejam compartilhadas de forma clara, organizada e no momento adequado.

## 2. Canais de comunicação

| Canal | Finalidade | Frequência |
|---|---|---|
| Reuniões de planejamento | Definir atividades e prioridades | A cada Sprint |
| Daily Scrum | Acompanhar o andamento das tarefas | Diariamente |
| Reuniões de revisão | Apresentar entregas realizadas | Ao final de cada Sprint |
| Relatórios | Registrar evolução e pendências | Semanalmente |
| Documentação no GitHub | Centralizar informações e decisões | Sempre que necessário |

## 3. Responsabilidades

- Gerente do projeto: acompanhar prazos e compartilhar informações gerais.
- Product Owner: comunicar prioridades e requisitos.
- Scrum Master: facilitar reuniões e apoiar a comunicação.
- Equipe de desenvolvimento: informar andamento, dificuldades e impedimentos.

## 4. Boas práticas de comunicação

- Utilizar linguagem clara e objetiva.
- Registrar decisões importantes.
- Compartilhar atualizações regularmente.
- Comunicar riscos e atrasos com antecedência.
- Manter a documentação organizada.

## 5. Resultados esperados

- Maior integração entre os envolvidos.
- Redução de falhas de comunicação.
- Melhor acompanhamento das atividades.
- Mais transparência nas decisões.
- Maior organização do projeto.

## 6. Considerações finais

O plano de comunicação contribui para manter todos os envolvidos alinhados e facilitar o acompanhamento das entregas do CompraFácil.

*Observação: este plano representa uma proposta de comunicação para o projeto e deverá ser ajustado conforme a equipe e os canais efetivamente utilizados.*
