# 📌 Projeto CompraFácil
## Planejamento e Gestão de Projeto de TI

### 1. 	📋 Apresentação do projeto

O CompraFácil é um projeto de desenvolvimento de um aplicativo de compras online, que tem como finalidade oferecer aos usuários uma plataforma simples e segura para realizar compras pela internet.

O aplicativo permitirá o cadastro de usuários, consulta de produtos, gerenciamento de carrinho, realização de pedidos e acompanhamento das compras.

### 2. Objetivo do projeto

O objetivo deste projeto é organizar e acompanhar o desenvolvimento de um aplicativo de compras online, desde o planejamento até a entrega. A proposta é definir as atividades, distribuir as responsabilidades, acompanhar os prazos e garantir que tudo seja realizado conforme o que foi planejado.

### 3. Justificativa

A proposta surgiu da necessidade de oferecer uma experiência de compra online mais prática e acessível, permitindo que os usuários realizem suas compras de maneira rápida e organizada.

### 4. Escopo do projeto

O aplicativo deverá contar com as seguintes funcionalidades:

- Cadastro e login de usuários.
- Consulta e pesquisa de produtos.
- Adição e remoção de produtos do carrinho.
- Finalização de pedidos.
- Acompanhamento de pedidos.
- Testes e validação das funcionalidades.

### 5. Resultados esperados

- Aplicativo funcional e acessível.
- Funcionalidades desenvolvidas conforme os requisitos.
- Entregas realizadas dentro do cronograma planejado.
- Testes executados antes da entrega.
- Documentação das atividades e resultados do projeto.

### 6. Prazo estimado

O projeto terá duração estimada de 12 semanas, contemplando planejamento, desenvolvimento, testes e entrega da primeira versão do aplicativo.

### 7. Metodologia

Para organizar o projeto, será utilizada a metodologia Scrum, dividindo as atividades em etapas menores chamadas sprints. Dessa forma, será possível acompanhar o andamento das tarefas, verificar o que já foi concluído e identificar o que ainda precisa ser feito.
