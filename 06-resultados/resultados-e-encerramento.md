# Resultados Esperados e Encerramento — CompraFácil

## 1. Objetivo

Este documento apresenta os resultados esperados para o projeto CompraFácil, considerando o planejamento, as atividades previstas e as entregas organizadas ao longo das 12 semanas.

## 2. Resultados esperados

Com o desenvolvimento do projeto, espera-se alcançar os seguintes resultados:

- Disponibilizar uma plataforma de compras online de fácil utilização.
- Permitir o cadastro e acesso dos usuários.
- Facilitar a consulta e pesquisa de produtos.
- Oferecer funcionalidades para gerenciamento do carrinho de compras.
- Permitir a finalização e o acompanhamento de pedidos.
- Garantir maior organização e controle das atividades do projeto.

## 3. Indicadores de acompanhamento

Para avaliar a evolução do projeto, serão considerados os seguintes indicadores:

| Indicador | Objetivo |
|---|---|
| Cumprimento do cronograma | Acompanhar os prazos das atividades. |
| Entregas das Sprints | Monitorar as entregas planejadas e realizadas. |
| Atividades concluídas | Verificar a evolução das tarefas. |
| Riscos identificados | Acompanhar possíveis impactos no projeto. |
| Testes realizados | Verificar a qualidade das funcionalidades. |

## 4. Critérios para encerramento

O encerramento do projeto deverá considerar:

- Conclusão das funcionalidades previstas no escopo.
- Realização dos testes e validações.
- Registro das pendências identificadas.
- Revisão da documentação do projeto.
- Avaliação das entregas em relação aos objetivos estabelecidos.

## 5. Lições aprendidas

Ao longo do projeto, deverão ser registradas oportunidades de melhoria relacionadas a:

- Planejamento e organização das atividades.
- Comunicação entre os envolvidos.
- Gerenciamento de prazos.
- Identificação e tratamento de riscos.
- Priorização das demandas.
- Acompanhamento das entregas.

## 6. Considerações finais

O projeto CompraFácil foi estruturado com base nas práticas de gestão de projetos e na metodologia ágil Scrum.

A organização do Backlog do Produto, o planejamento das Sprints, o acompanhamento por Kanban, o gerenciamento de riscos e o cronograma contribuem para uma visão estruturada do desenvolvimento.

A documentação permite demonstrar a aplicação de conceitos de Gestão de Projetos de TI, desde o planejamento até a avaliação das entregas previstas.
