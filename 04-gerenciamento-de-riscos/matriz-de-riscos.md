# Matriz de Gerenciamento de Riscos — CompraFácil

## 1. Objetivo

Identificar os principais riscos que podem impactar o desenvolvimento do projeto CompraFácil, avaliando suas possíveis consequências e definindo ações preventivas e corretivas.

## 2. Identificação dos riscos

| ID | Risco identificado | Probabilidade | Impacto |
|---|---|---|---|
| R01 | Atraso no cronograma | Média | Alto |
| R02 | Mudanças nos requisitos | Alta | Médio |
| R03 | Falhas nas funcionalidades | Média | Alto |
| R04 | Problemas de comunicação da equipe | Média | Médio |
| R05 | Indisponibilidade de recursos | Baixa | Alto |
| R06 | Falhas na validação do sistema | Média | Alto |

## 3. Plano de resposta aos riscos

| ID | Ação preventiva ou corretiva |
|---|---|
| R01 | Monitorar o cronograma e revisar as prioridades das atividades. |
| R02 | Registrar as mudanças e avaliar seus impactos no projeto. |
| R03 | Realizar testes durante o desenvolvimento. |
| R04 | Manter comunicação frequente e alinhamento entre os envolvidos. |
| R05 | Planejar os recursos necessários antecipadamente. |
| R06 | Definir critérios de aceitação e realizar testes de validação. |

## 4. Monitoramento

Os riscos deverão ser acompanhados durante todo o projeto, com revisões periódicas para identificar mudanças na probabilidade e no impacto.

Caso algum risco se concretize, deverão ser avaliadas ações corretivas para reduzir seus efeitos sobre o cronograma e as entregas.

## 5. Resultado esperado

Com o gerenciamento de riscos, espera-se reduzir possíveis impactos negativos, melhorar a previsibilidade das entregas e contribuir para o cumprimento dos objetivos do CompraFácil.
